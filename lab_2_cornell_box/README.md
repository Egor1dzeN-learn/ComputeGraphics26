# Корнелльская комната на Python

Сцена построена с помощью трассировки лучей на CPU: красная и зелёная стены имеют матовое диффузное отражение, на потолке расположен прямоугольный площадной источник света, внутри находятся блок и шар. Тени получаются мягкими благодаря выборке множества точек источника и проверке лучей до каждой из них. Небольшая постоянная фоновая составляющая приближает непрямое освещение; полноценные переотражения света не моделируются.

## Запуск в Windows

Установите Python с pip и запустите двойным щелчком `run.bat` или из PowerShell:

```powershell
cd lab_2_cornell_box
.\run.bat
```

Скрипт создаёт локальное виртуальное окружение `.venv`, устанавливает зависимости и запускает рендеринг. Нужен доступ к пакетам PyPI при первой установке. Изображение сохраняется как `cornell_box.png` и открывается стандартной программой. Компиляция не требуется.

Параметры можно передать скрипту:

```powershell
.\run.bat --width 800 --height 800 --samples 128 --output result.png
.\run.bat --width 300 --height 300 --samples 16 --no-show
```

`--samples` задаёт количество проб источника на пиксель: большее значение уменьшает шум, но увеличивает время расчёта. `--seed` задаёт начальное состояние генератора случайных чисел. Для ручного запуска установите зависимости из `requirements.txt` и выполните `python main.py`.

Схема комнаты вдохновлена [Cornell box](https://en.wikipedia.org/wiki/Cornell_box).
